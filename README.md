This repository contains a comprehensive Power BI project designed to analyze and visualize complex global datasets. The core objective of this project is to transform raw data into actionable business intelligence, focusing on regional performance, sales trends, and operational efficiency.

Key Features
Dynamic Global Dashboard: An interactive multi-page report providing a high-level view of performance across international markets.

Advanced Data Modeling: Implements a robust star-schema architecture with optimized relationships to handle large-scale data efficiently.

Key Performance Indicators (KPIs): Custom DAX measures developed to track Year-over-Year (YoY) growth, profit margins, and regional sales distribution.

User-Centric Design: Utilizes custom themes and intuitive navigation to ensure a seamless experience for stakeholders.

Technical Tools Used
Power BI Desktop: For data modeling, DAX development, and report visualization.

Power Query (M): Used for advanced data cleaning, transformation, and ETL processes.

DAX (Data Analysis Expressions): Created for complex calculated columns and measures.
